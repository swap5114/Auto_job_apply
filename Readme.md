# Job Application Multi-Agent System

A personal automation pipeline that handles the repetitive parts of job hunting. It finds job leads from job boards, company pages, and X, scrapes and structures them into a single tracked list, then uses an LLM to tailor my resume and draft outreach for each lead. Nothing goes out automatically — every tailored resume and draft email sits in a review queue until I approve it. Once approved, it's sent via Gmail, and the system tracks replies to trigger follow-ups on leads that go quiet. Built and driven by me as a learning project; Claude Code is used as a pair-programming guide, not an autonomous builder.
